# Registro e Licenças de Ícones — Onde Pego

Todos os ícones vetoriais inline utilizados no projeto (disponíveis em `src/components/ui/Icon.tsx`) são desenhados em SVG com padrão unificado (viewBox 0 0 24 24, traço uniforme 2.2, `currentColor`, `strokeLinecap="round"`, `strokeLinejoin="round"`).

## Lista de Ícones (20 Ícones Oficiais)

1. `search` — Lupa de busca
2. `pin` — Pino de localização no mapa
3. `cross` — Cruz da saúde / farmácia
4. `a11y` — Acessibilidade humana
5. `clock` — Relógio de atualização de dados e plantão
6. `heart` — Coração (atalho de pressão alta)
7. `drop` — Gota (atalho de diabetes)
8. `wind` — Vento / respiração (atalho de asma)
9. `pulse` — Pulso / atividade (atalho de colesterol)
10. `check` — Marcação de confirmação e resultado exato
11. `back` — Seta para voltar
12. `doc` — Documento / receita médica
13. `chev` — Chevron indicador
14. `share` — Compartilhamento de dados
15. `list` — Lista de estabelecimentos
16. `map` — Mapa desdobrado
17. `download` — Download de mapa offline
18. `close` — Fechar modal / diálogo
19. `filter` — Filtro de busca de unidades
20. `info` — Informação e resultado aproximado
